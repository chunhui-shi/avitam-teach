# Official Python tutorial sample material

The Python Software Foundation publishes downloadable plain-text documentation.
Its documentation is licensed under the Python Software Foundation License
Version 2; examples and recipes are also available under the Zero-Clause BSD
License.

Run `./fetch.sh` to download the pinned Python 3.14 documentation archive from
`docs.python.org`, verify its SHA-256 digest, and produce one uploadable tutorial
file under `generated/`. The generated file retains the PSF copyright notice,
license reference, source URL, pinned version, and a summary of the mechanical
changes. The complete upstream license is extracted beside it.

Upload `generated/python-3.14-tutorial.txt` through an instructor course's
Materials tab. Do not upload the ZIP archive itself. The application accepts
text, Markdown, and PDF material, not archives.

Official sources:

- https://docs.python.org/3/download.html
- https://docs.python.org/3/license.html
